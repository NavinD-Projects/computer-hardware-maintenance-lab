# Project 1: Computer Hardware Assembly and Troubleshooting

## Objective

Learn to identify common desktop computer components, understand their functions, and follow a safe, systematic troubleshooting and preventive-maintenance process.

## Scope

This workbook focuses on component identification and safe inspection. Physical assembly or component replacement should be performed only on equipment you own or are authorised to service.

## Components to identify

| Component | Purpose | What to record |
|---|---|---|
| Motherboard | Connects and allows components to communicate | Form factor/model, if visible |
| CPU | Executes instructions | Model, if visible |
| RAM | Temporary working memory | Type/capacity, if visible |
| SSD/HDD | Long-term storage | Type/capacity |
| PSU/SMPS | Supplies power to components | Rated wattage/model, if visible |
| CPU cooler/fans | Helps manage temperature | Fan locations |
| Network interface | Provides wired/wireless connectivity | Ethernet/Wi-Fi |
| Case | Houses and protects components | Form factor |

## Safety first

- Shut down the computer and unplug it before any external inspection.
- Never open a power supply unit (PSU); dangerous voltages may remain inside.
- Avoid touching component contacts and circuit traces.
- Use ESD precautions where available.
- Do not force connectors or components.
- If you are unsure, stop and ask a qualified technician.
- For a laptop, do not open the chassis or disconnect an internal battery unless trained and authorised.

## Activities

### Activity A — Component identification
1. Record the computer make/model and whether it is a desktop or laptop.
2. Identify the components that are visible without unsafe disassembly.
3. Find the manufacturer's specifications where possible.
4. Add your own labelled photo or a hand-drawn component diagram to `evidence/`.

### Activity B — Safe external inspection
1. Check the power cable, display cable, ventilation openings, keyboard, mouse, and external ports.
2. Look for blocked vents, unusual noise, visible damage, or loose external connections.
3. Record observations. Do not open equipment if you are not authorised.

### Activity C — Troubleshooting method
For each issue, document: symptom → checks → finding → action → retest result.

| Symptom | Safe initial checks |
|---|---|
| No power | Check wall socket, power cable, power strip and external switch |
| No display | Check monitor power/input and display cable |
| Slow computer | Check free storage, startup apps and resource usage |
| Overheating | Check ventilation and external dust blockage; shut down if temperatures are unsafe |
| No sound | Check volume, output device and audio connection |

These are diagnostic starting points, not guaranteed fixes.

## Evidence to add

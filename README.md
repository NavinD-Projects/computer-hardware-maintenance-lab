# Project 2: Operating System Installation and Maintenance

## Objective

Understand Windows installation concepts and practise routine system-maintenance tasks using a working Windows computer.

## Important precautions

- Back up important files before making changes.
- Do not format, delete, or resize partitions on your main computer as a practice exercise.
- Do not reinstall Windows unless you have a verified backup, installation media, licence/activation details where applicable, and a recovery plan.
- Use a spare PC or virtual machine for installation practice if possible.
- Download drivers and installation files only from official manufacturer or Microsoft sources.

## Activities

### Activity A — Collect system information
1. Open Settings → System → About.
2. Record Windows edition/version, processor, and installed RAM.
3. Open System Information (`msinfo32`) and note relevant system details.
4. Take a screenshot with personal identifiers hidden.

### Activity B — Device Manager
1. Right-click Start → Device Manager.
2. Expand categories such as Display adapters, Network adapters, and Sound, video and game controllers.
3. Note device names and whether any warning symbols appear.
4. Do not uninstall drivers just for practice.

### Activity C — Disk Management (view-only)
1. Right-click Start → Disk Management.
2. Observe the disk and volume layout.
3. Record drive letters and volume sizes.
4. Do not delete, format, shrink, or extend partitions on a live system for this exercise.

### Activity D — Maintenance review
1. Review available storage in Settings → System → Storage.
2. Review Windows Update status.
3. Review startup apps in Task Manager.
4. Record any recommended updates or maintenance actions; do not disable security software.

### Activity E — Installation concepts
Document the high-level Windows installation workflow: backup, verify hardware requirements, obtain official installation media, boot from media, select the correct target, complete setup, install updates/drivers, and verify activation. Practise on a spare device or VM rather than risking your primary device.
